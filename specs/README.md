# Desenvolvimento Orientado por Especificações

As funcionalidades começam com uma especificação aprovada neste diretório. Mantenha
cada especificação pequena o suficiente para ser implementada e verificada de forma
independente.

Fluxo de trabalho sugerido:

1. Descreva o problema, os objetivos, o que não faz parte do escopo, os cenários de uso e os critérios de aceitação.
2. Revise a especificação e resolva as dúvidas em aberto antes da implementação.
3. Derive o plano de implementação e os testes a partir dos critérios de aceitação.
4. Implemente somente o escopo acordado e, em seguida, execute os testes relevantes e o build.
5. Atualize a especificação se a implementação revelar uma mudança necessária e registre o motivo.

Use o arquivo [`_template.md`](_template.md) como ponto de partida para cada funcionalidade.
